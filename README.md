## 1. Project Overview

BTM WP is a custom WordPress theme engineered for a B2B corporate client. The project focused on delivering a high-performance, secure, and easily maintainable institutional website that clearly communicates the company's value proposition, services, and corporate news, fully managed via an intuitive ACF Pro backend.

## 2. The Problem

The client's previous digital presence was outdated, difficult to update, and did not accurately reflect their current market position. They required a modern platform that could serve as a reliable lead generation tool while providing their internal team with a frictionless content management experience.

---

## 3. The Solution & Architecture

A bespoke WordPress theme built from the ground up, avoiding off-the-shelf templates to ensure maximum performance, security, and brand alignment.

### Architecture

- **Custom Post Types:** Utilized for separating distinct content streams, such as 'Services' and 'Case Studies', from standard blog posts.
- **ACF Integration:** Extensive use of Advanced Custom Fields to map specific data points (e.g., service icons, case study metrics) directly to the WordPress admin, ensuring editors cannot break the frontend layout.
- **Clean Codebase:** A streamlined `functions.php` and logical directory structure (`inc/`, `template-parts/`) that follows WordPress coding standards for long-term maintainability.

---

## 4. Technologies Used

- **CMS & Backend:** WordPress 6.0+, PHP 8.0+, MySQL
- **Content Management:** ACF Pro
- **Styling:** Custom CSS

## 5. Design Process & UI/UX

The design aesthetic is corporate, reliable, and straightforward, tailored to a B2B audience. The user journey is designed to efficiently route prospective clients from initial discovery to specific service details and ultimately to a lead capture form.
